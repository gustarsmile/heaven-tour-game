- 版本：v1.0（2026-08-29）

- 依據素材：《天堂遊記》原著（台中聖賢堂扶鸞，濟佛導遊、楊生採著；文字版 https://www.taolibrary.com/category/category48/c48001b.htm ，正文 36 回＋濟公活佛傳＋懿旨玉旨序）
- 素材摘要：本資料夾 `天堂遊記素材摘要.md`（36 回逐回：畫面／教義／可遊戲化素材／金句）；原文備份 `天堂遊記原文/NN.txt`

## 一、定位與目標

| 面向 | 決定 |
|------|------|
| 目標對象 | 廟宇／信眾推廣，善書勸化（同地獄篇） |
| 載體 | 網頁遊戲，掃 QR 或點 LINE 連結即玩，免安裝 |
| 模式 | 完整版（13 站，目標 30–50 分鐘；階段 2 實測估算 30–60 分，階段 4 潤飾時裁決收斂文字量或修訂本欄）／精簡版（7 站，12–20 分鐘），同一套內容與美術，`flow.json` 的 `modes` 切換 |
| 調性 | 莊嚴清明：金光、雲彩、宮闕；與地獄篇同一位「畫師」的天與地 |
| 核心對稱 | 地獄篇是**孽鏡照過去**（看別人的因果、審自己的心）；天堂篇是**花樹映現在**（看自己的樹、養自己的心） |

### 素材特性與設計對策

《地獄遊記》是「一回一罪魂訪談」，天然是判案關卡；《天堂遊記》是「一宮一說法」，36 回九成是仙佛開示，沒有破綻可點、沒有案子可判。本作以原著唯一自帶的可視化成長系統——**眾生原靈花樹**（第 13–15 回）——為主機制，五華宮的五行五常為五條心性軸，陰陽界三岔路與通天五段為結算，說法內容轉為「兩難抉擇＋帝君考題＋天音卡」。

### 教育目標

1. 讓玩家透過「自己的樹會因選擇而變」理解「種瓜得瓜、修道即改良品種」的原著核心。
2. 將 36 回說法轉為十三站可互動的關卡，成為《天堂遊記》原著的入口。
3. 中段三官殿的「懺悔補過」與結局的「樹的來歷」總覽，讓勸化不只是判定，而是看見「哪一個選擇讓樹長成這樣」。

## 二、敘事流程

```
序章·陽間一日（五情境）→ 夜遇濟公·天水·蓮台 → 南天門（教學）→ 三清河（淨身關）
→ 東華·南華·西華·北華·中華五宮（五常兩難，東華讀樹）→ 三教聖境（見聞）
→ 三官殿（考核·懺悔補過）→ 忠義殿·孝子殿 → 陰陽界（結算·通天五段）[八仙支線]
→ 回程南天門 → 瑤池盛會（結局·樹的來歷）
```

**玩家身分**：一名普通人（不扮演楊生，避免扮演真實人物）。序章度過平凡一天；當夜濟公乘蓮台來接，開場鉤子：「天上有一棵樹，掛著你的名字。」

## 三、核心機制

### 3.1 明線：悟性值（0–100，顯示）

沿用地獄篇公式：原始分／該模式滿分 ×100，再按惡選扣分（每筆 `KARMA_PENALTY`×權重）。答錯由濟公提示後可重答，重答不得分。

| 行為 | 得分 |
|------|------|
| 東華宮「看樹況猜因由」案例題（4–5 題） | 各 +5 |
| 南華／西華／北華／中華每宮一題帝君考題（說法後；東華宮以案例樹題代替） | 各 +5 |
| 三教聖境語錄題（3 題） | 各 +5 |
| 陰陽界三位歸天者「他為何能直升／為何要轉世」（3 題） | 各 +5 |
| 三清河淨身關、孝子殿（各一題） | 各 +5 |
| 八仙支線完成 | 隱藏功德 +10 |

### 3.2 暗線：原靈樹五軸（不顯示數值，只在四次看樹揭曉）

五常／五行／五華宮綁到樹的五個部位，症狀用語全部取自原著讀樹段落：

| 軸（代號） | 宮 | 部位 | 佳 | 傷（原著症狀） |
|---|---|---|---|---|
| 信 `xin` | 中華・土 | **幹** | 幹直圓通 | 裂痕（常犯規矩）、突節（想不通） |
| 仁 `ren` | 東華・木 | **根** | 根深葉盛 | 半屏山「一半青山一半紅土」（道志崩頹） |
| 智 `zhi` | 北華・水 | **葉** | 葉茂青翠 | 葉細枯黃（離開法水灌溉）、無葉多枝「千手觀音」（投機取巧） |
| 禮 `li` | 南華・火 | **花** | 花繁結子 | 花枝有折（桃花過渡）、紅葉（血氣酒氣上沖） |
| 義 `yi` | 西華・金 | **果** | 結果纍纍 | 落葉落果、青果未熟 |

**寫入來源**：序章五情境（權重 ×2）、南天門／三清河、五華宮兩難、孝子殿三段抉擇、旅途中不標示計分的反應題。每筆 +1（善）／0（中性）／−1（惡）。

**結算**：單軸總和 ≥ +1 為「佳」、0 為「平」、≤ −1 為「傷」。五軸總和 → 樹況五級：枯萎（≤ −5）／稀疏（−4～−1）／平常（0～+2）／茂盛（+3～+6）／結果纍纍（≥ +7）。五軸總和 ≥ 0 判「樹・善」，否則「樹・傷」（用於陰陽界分流與結局矩陣）。門檻於階段 3 依實際內容題數校準，寫在 `tree.json`。

### 3.4 陰陽界結算關（`review`）

1. **三岔路口**：依「樹・善／傷」分流。善 → 濟公領你走上黃金大道，與三位歸天者（廟祝義工／背業轉世者／清修僧人）同行；傷 → 濟公攔下「這條路你還走不得」，只能站在路口旁觀三人走過。兩種分流都有同樣三題考題（各 +5，悟性滿分不因分流而異——五軸與悟性不互相連坐），差別只在敘事框架與濟公語氣。
2. **通天五段**：腳（信）→ 六根（禮）→ 肚腸（義）→ 心（仁）→ 絕塵嶺（智），每段回放該軸所有選擇——這是天堂篇的「孽鏡反照」戲劇版：濟公旁白、逐筆點名「你在某站選了……」，看完才登瑤池。

### 3.5 結局：四象限

悟性（≥ 70 為高）× 樹況（善／傷）：

| | 樹・善 | 樹・傷 |
|---|---|---|
| **悟性・高** | 道果圓熟・蓮台九品 | 滿樹青果・知而未行 |
| **悟性・低** | 不識經文・根深葉茂 | 種子未萌・再世重修 |

- 每結局各有專屬結語與濟公評語；「知而未行」「再世重修」由濟公點出序章的具體選擇作勸勉。
- 通關生成**稱號分享卡**（Canvas 合成 PNG）：稱號＋悟性值＋一句戒語＋遊戲 QR。分享卡不塞五軸；「樹的來歷」頁本身可截圖分享。

### 3.6 「樹的來歷」總覽

**位置**：瑤池結局稱號公布後（★④ 大圖 → 「這棵樹是怎麼長成的？」），並常駐善書冊「我的樹」頁籤，通關後隨時可回看。

**結構**：一棵樹拆成五個部位，每部位一段「症狀 → 來歷」：

```
🌳 幹（信）  裂痕一道 ────────────── 總計 −1
   ├ 序章・答應同事的事後來沒做          損傷 −2（序章 ×2）
   ├ 中華宮・「先答應再說，做不到再解釋」  損傷 −1
   ├ 孝子殿・「守住對祖母的承諾」          澆灌 +1
   └ 三官殿・地官赦罪：你選擇修枝補過此軸  補過 +1
   帝君語：「幹上有一條裂痕，是常犯規矩之故；幸而知過能改，裂處已見新皮。」
```

每一行＝一次選擇：站名・當時選的那句話・澆灌／持平／損傷＋數值。軸總計決定部位狀態，狀態決定帝君評語（套原著讀樹句型），評語末句依「有無補過」兩版。五部位之下是總結：五軸總和 → 樹況等級；悟性逐站得分 → 蓮台大小。

**分工**：通天五段是戲劇版（有旁白有情緒），總覽是成績單版（一頁看完、可回看）。兩者共用同一份選擇紀錄，只有一套邏輯。

### 3.7 教育收束：善書冊與天音卡

- 每站結束跳出一張「**天音卡**」：說法白話 → 原文金句逐字 → 「出自《天堂遊記》第 X 回」＋文字版連結（`c48001b/NN.htm`，NN＝X+2 兩位數補零，如第 1 回 → `03.htm`）。
- 天音卡集入善書冊，通關後可回顧；未拿滿的卡提示重玩補完。
- 善書冊新增「我的樹」頁籤（§3.6 總覽常駐）。
